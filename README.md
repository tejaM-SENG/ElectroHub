# ElectroHub – E-Commerce Website

A modern electronics e-commerce website featuring a clean interface, product-focused layouts, and responsive design.

## 📌 Overview

ElectroHub is an electronics shopping website UI project designed to provide a structured and user-friendly online shopping experience.

The website focuses on presenting electronic products through organized layouts, clear product sections, and a consistent visual design.

It demonstrates frontend development skills through responsive page layouts, reusable styling, and Bootstrap components.

## ✨ Features

- **E-Commerce UI:** Electronics shopping-themed website design.
- **Product Presentation:** Structured layouts for displaying electronic products.
- **Category-Based Layouts:** Organized product browsing sections.
- **Responsive Design:** Adapts to desktop, tablet, and mobile screens.
- **Navigation:** Consistent navigation and page structure.
- **Modern Styling:** Clean layouts, typography, buttons, and product sections.
- **Bootstrap Components:** Uses Bootstrap for responsive layouts and UI elements.

## 🛠️ Technologies Used

- HTML5
- CSS3
- Bootstrap 5


## 🚀 Getting Started

### 1. Clone the Repository

```bash
git clone https://github.com/tejaM-SENG/ElectroHub
```

### 2. Navigate to the Project

```bash
cd ElectroHub
```

### 3. Run the Website

Open the main HTML file in your browser.

For development, you can use the **Live Server** extension in Visual Studio Code.
